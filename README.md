# Customer Churn Prediction

## Overview
A machine learning project focused on predicting customer churn using classical classification algorithms and evaluating their performance.

## Models
- Logistic Regression
- Decision Tree
- K-Nearest Neighbors (KNN)
- Random Forest
- Support Vector Machine (SVM)

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

## Key Tasks
- Data preprocessing and feature scaling
- Model training and performance comparison
- Evaluation using Accuracy, Precision, Recall, F1-score, and ROC-AUC
- KNN hyperparameter tuning
- SVM optimization using GridSearchCV
- Class imbalance analysis using `class_weight="balanced"`

## Visualizations
- Model Performance Comparison
- KNN Hyperparameter Tuning
- SVM GridSearchCV Results

## How to Run
```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
jupyter notebook
```
